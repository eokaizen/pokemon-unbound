# pokemon-unbound - Download and Play
Launcher nativo para Pokemon Unbound v2.1.1.1 no estilo bbport.

## Para JOGAR (sem comandos)
1. Baixe o `pokemon-unbound_1.0.0_x64-setup.exe` em Releases
2. Instale e coloque seu `Pokemon Unbound v2.1.1.1.gba` de 32MB na pasta `/game/`
3. Abra `pokemon-unbound.exe` > Clique em JOGAR

Validação local, janela escalável 1x-8x, áudio WASAPI, teclado + gamepad.

## Legal
Este projeto NÃO distribui ROM. Use apenas sua cópia legalmente obtida de Pokemon Unbound. Core mgba MPL-2.0 compilado estaticamente dentro do exe.
